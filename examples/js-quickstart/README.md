# Orvano JavaScript quickstart

The finished app of the [JavaScript quickstart](https://orvano.dev/docs/quickstarts/js/): sign up, sign in, see your name and email, and sign out, with `@orvano/js` in plain TypeScript and Vite. The session lives in the browser's localStorage.

To run it, start Orvano locally ([Run Orvano locally](https://orvano.dev/docs/local/)), add a Web platform `localhost` to your project, then:

```bash
cp .env.example .env.local   # then set VITE_ORVANO_PROJECT
npm install
npm run dev
```

Open http://localhost:5173.
