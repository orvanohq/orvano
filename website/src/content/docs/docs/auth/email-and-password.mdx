Email and password is the flow every quickstart builds. This page collects the calls in one place, with what each one does to the session. The [Next.js](/docs/quickstarts/nextjs/), [Flutter](/docs/quickstarts/flutter/), and [JavaScript](/docs/quickstarts/js/) quickstarts show them in a finished app.

## Sign up

[`account.create`](/docs/api/operations/accountcreate/) creates the user and signs them in. The SDK stores the new session.

<Tabs syncKey="sdk">
  <TabItem label="JavaScript">

```ts
const { user, isNewUser } = await orvano.account.create({ email, password, name })
```

  </TabItem>
  <TabItem label="Next.js">

```ts
'use server'
// In a server action, so the SDK can set the session cookies.
await (await orvano()).account.create({ email, password, name })
```

  </TabItem>
  <TabItem label="Flutter">

```dart
final result = await orvano.account.create(
  CreateAccountRequest(email: email, password: password, name: name),
);
```

  </TabItem>
</Tabs>

- The email must be unused in the project, ignoring case; a taken one gets [`user_already_exists`](/errors/user_already_exists/).
- The password needs 8 to 256 characters, or the call gets [`invalid_password`](/errors/invalid_password/).
- `name` is optional.
- To send a verification email in the same call, pass `verificationRedirectUrl`; see [Email verification](/docs/auth/email-verification/#send-it-at-sign-up).

## Sign in

[`account.createPasswordSession`](/docs/api/operations/accountcreatepasswordsession/) signs an existing user in. Each sign in opens a new session, so a user can be signed in on many devices at once.

<Tabs syncKey="sdk">
  <TabItem label="JavaScript">

```ts
const { user } = await orvano.account.createPasswordSession({ email, password })
```

  </TabItem>
  <TabItem label="Next.js">

```ts
'use server'
await (await orvano()).account.createPasswordSession({ email, password })
```

  </TabItem>
  <TabItem label="Flutter">

```dart
await orvano.account.createPasswordSession(
  CreatePasswordSessionRequest(email: email, password: password),
);
```

  </TabItem>
</Tabs>

A wrong email and a wrong password get the same [`invalid_credentials`](/errors/invalid_credentials/), so nobody can find out which emails have accounts. A blocked user with the right password gets [`user_blocked`](/errors/user_blocked/). After 10 tries in 15 minutes for one email, Orvano answers [`rate_limited`](/errors/rate_limited/) with the seconds to wait.

## Sign out

[`account.deleteCurrentSession`](/docs/api/operations/accountdeletecurrentsession/) ends this session on Orvano and forgets it on the device. The user's other sessions stay.

<Tabs syncKey="sdk">

```ts

```

  </TabItem>
  <TabItem label="Next.js">

```ts

```

  </TabItem>
  <TabItem label="Flutter">

```dart

```

  </TabItem>
</Tabs>

## Change the password

[`account.updatePassword`](/docs/api/operations/accountupdatepassword/) needs the current password, and ends every other session of the user. This session stays signed in.

<Tabs syncKey="sdk">
  <TabItem label="JavaScript">

```ts
await orvano.account.updatePassword({ currentPassword, newPassword })
```

  </TabItem>
  <TabItem label="Next.js">

```ts
'use server'
await (await orvano()).account.updatePassword({ currentPassword, newPassword })
```

  </TabItem>
  <TabItem label="Flutter">

```dart
await orvano.account.updatePassword(
  UpdatePasswordRequest(currentPassword: currentPassword, newPassword: newPassword),
);
```

  </TabItem>
</Tabs>

A user who signed up without a password (with a [magic link](/docs/auth/magic-links/) or an [emailed code](/docs/auth/email-codes/)) can set one without `currentPassword`, but only within 10 minutes of signing in; after that the call gets [`reauthentication_required`](/errors/reauthentication_required/). For a forgotten password, see [Password reset](/docs/auth/password-reset/).

## Delete the account

[`account.delete`](/docs/api/operations/accountdelete/) deletes the user and every session, for good. It asks for the password the same way:

<Tabs syncKey="sdk">
  <TabItem label="JavaScript">

```ts
await orvano.account.delete({ password })
```

  </TabItem>
  <TabItem label="Next.js">

```ts
'use server'
await (await orvano()).account.delete({ password })
```

  </TabItem>
  <TabItem label="Flutter">

```dart
await orvano.account.delete(DeleteAccountRequest(password: password));
```

  </TabItem>
</Tabs>

## Show the signed in user

[`account.get`](/docs/api/operations/accountget/) answers with the user, or throws a 401 when nobody is signed in. Each quickstart wraps it in a `currentUser` helper that answers null instead. [`account.update`](/docs/api/operations/accountupdate/) changes the user's `name` and `metadata`.
