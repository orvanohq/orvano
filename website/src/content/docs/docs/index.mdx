Orvano is an open source backend you host yourself. One install gives you a console that holds many projects, and each project gets auth, a Postgres database, storage, functions, realtime, messaging, webhooks, jobs, and backups. Today Orvano ships auth: sign up and sign in with a password, email verification, password reset, magic links, and email codes.

You talk to a project through one of five SDKs, all generated from one API contract:

- **Client SDKs** run where your users are: `@orvano/js` in the browser, `@orvano/nextjs` in Next.js, `orvano_flutter` in Flutter apps. They sign users in and act as them.
- **Server SDKs** run on your own server with an API key: `orvano_dart` and the `Orvano` NuGet package. They manage users and verify the tokens your users send.
