You build a Flutter app where people sign up with an email and a password, sign in, see their name and email, and sign out. It uses `orvano_flutter` {version}, runs on the web, iOS, and Android from one codebase, and keeps the session in the platform's secure storage (the Keychain on iOS, the Keystore on Android). It takes about fifteen minutes.

The finished app is [`examples/flutter-quickstart`](https://github.com/orvanohq/orvano/tree/main/examples/flutter-quickstart) in the Orvano repo. Every file below comes from it, and CI runs it on every change, on Chrome, and every night on the iOS simulator and the Android emulator.

## 4. Let the app reach your local Orvano

Your local Orvano answers on `http://localhost:7700`, plain HTTP. Each platform needs a small change to reach it while you develop.

<Tabs syncKey="flutter-platform">
  <TabItem label="Web">
    Nothing to change. Run the app on port 5050 (step 7), which the Web platform `localhost` covers.
  </TabItem>
  <TabItem label="iOS">
    iOS allows only HTTPS unless you say otherwise. Add this to the `<dict>` in `ios/Runner/Info.plist`, which allows plain HTTP to local addresses only:

    <ExampleCode example="flutter-quickstart" file="ios/Runner/Info.plist" region="ats" lang="xml" title="ios/Runner/Info.plist" />

    The iOS simulator shares your Mac's network, so `localhost` reaches Orvano directly.
  </TabItem>
  <TabItem label="Android">
    Android allows only HTTPS unless you say otherwise. Allow plain HTTP to `localhost` in debug builds only: add this file,

    <ExampleCode example="flutter-quickstart" file="android/app/src/debug/res/xml/network_security_config.xml" lang="xml" />

    and point the debug manifest at it:

    <ExampleCode example="flutter-quickstart" file="android/app/src/debug/AndroidManifest.xml" region="cleartext" lang="xml" title="android/app/src/debug/AndroidManifest.xml" />

    The emulator's own `localhost` is the emulator, not your computer. `adb reverse` forwards its port 7700 to yours, so the app reaches Orvano at the same `http://localhost:7700` as everywhere else. Run it once each time the emulator starts:

    <Code code="adb reverse tcp:7700 tcp:7700" lang="sh" />

    Don't use `10.0.2.2` instead: Orvano answers only on `localhost`.
  </TabItem>
</Tabs>

## 7. Try it

Run the app with your project ID:

<Tabs syncKey="flutter-platform">
  <TabItem label="Web">
    <Code code="flutter run -d chrome --web-port 5050 --dart-define=ORVANO_PROJECT=your-project-id" lang="sh" />
  </TabItem>
  <TabItem label="iOS">
    Open a simulator first (`open -a Simulator`), then:

    <Code code="flutter run -d iPhone --dart-define=ORVANO_PROJECT=your-project-id" lang="sh" />
  </TabItem>
  <TabItem label="Android">
    Start an emulator and run `adb reverse tcp:7700 tcp:7700` first, then:

    <Code code="flutter run -d emulator --dart-define=ORVANO_PROJECT=your-project-id" lang="sh" />
  </TabItem>
</Tabs>

<Steps>

1. Fill in the **Sign up** form and select **Sign up**. You should see "You're signed in" with your name and email.
2. Restart the app. You should still be signed in: the session is in secure storage.
3. Select **Sign out**. You should see the two forms again.
4. Fill in the **Sign in** form with the same email and password. You should see your name and email again.
5. Try signing in with a wrong password. You should see Orvano's message under the form.

</Steps>

The new user is in the console too: open your project's **Users** page.
