You build a small web app in plain TypeScript where people sign up with an email and a password, sign in, see their name and email, and sign out. It uses `@orvano/js` {version} in the browser, with Vite to serve it. The session lives in the browser's `localStorage`, so people stay signed in across reloads. It takes about ten minutes.

The finished app is [`examples/js-quickstart`](https://github.com/orvanohq/orvano/tree/main/examples/js-quickstart) in the Orvano repo. Every file below comes from it, and CI runs it on every change.

## 7. Try it

Run `npm run dev` and open `http://localhost:5173`.

<Steps>

1. Fill in the **Sign up** form and select **Sign up**. You should see "You're signed in" with your name and email.
2. Reload the page. You should still be signed in: the session is in `localStorage`.
3. Select **Sign out**. You should see the two forms again.
4. Fill in the **Sign in** form with the same email and password. You should see your name and email again.
5. Try signing in with a wrong password. You should see Orvano's message under the form.

</Steps>

The new user is in the console too: open your project's **Users** page.
