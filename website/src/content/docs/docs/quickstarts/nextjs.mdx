You build a Next.js App Router app where people sign up with an email and a password, sign in, see their name and email, and sign out. It uses `@orvano/nextjs` {version}: server actions sign people in, and the session lives in two cookies. It takes about ten minutes.

The finished app is [`examples/nextjs-quickstart`](https://github.com/orvanohq/orvano/tree/main/examples/nextjs-quickstart) in the Orvano repo. Every file below comes from it, and CI runs it on every change.

## 7. Try it

Run `npm run dev` and open `http://localhost:3000`.

<Steps>

1. Fill in the **Sign up** form and select **Sign up**. You should see "You're signed in" with your name and email.
2. Reload the page. You should still be signed in: the session is in the cookies.
3. Select **Sign out**. You should see the two forms again.
4. Fill in the **Sign in** form with the same email and password. You should see your name and email again.
5. Try signing in with a wrong password. You should see Orvano's message under the form.

</Steps>

The new user is in the console too: open your project's **Users** page.
