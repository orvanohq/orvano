## Why it happens

A new password is shorter than the project's minimum length, or longer than 256 characters, counted after Unicode normalization (NFKC). The minimum is 8 unless the project raised it (up to 64) on the Security page in the console; the error's detail names it. A password someone already has is never checked again, so this only happens at sign up, on a password change, on a reset, and when a server creates a user.

## How to fix

Ask for a password at least as long as the minimum the detail names, and show that rule next to the password field so people don't have to guess it. To change the minimum, open the project's **Security** page in the console and edit the Passwords card.
